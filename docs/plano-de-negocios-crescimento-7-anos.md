## 1. SUMÁRIO EXECUTIVO

Este plano estrutura a trajetória de uma empresa de energia do estágio atual (R$ 3M/ano) até um evento de saída com valuation de **R$ 1 bilhão** em 7 anos, via modelo **BOT — Build-Operate-Transfer**.

### A conta reversa do R$ 1 bilhão

```
  VALUATION ALVO:          R$ 1.000.000.000
  ÷ Múltiplo (10× EBITDA)  ─────────────────
  EBITDA NECESSÁRIO:         R$ 100.000.000
  ÷ Margem EBITDA (28%)    ─────────────────
  RECEITA NECESSÁRIA:        R$ 357.000.000
                             (arredondamos para R$ 360M)
  Portfólio necessário:      ~225 projetos operacionais
  AUM total:                 225 × R$6,2M = R$ 1,395B
  Check AUM (0,72×):        R$ 1,395B × 0,72 ≈ R$ 1,004B ✓
```

## 4. OS TRÊS MOTORES DE RECEITA

Para atingir R$ 360M em receita, o modelo opera com **três motores simultâneos** que se reforçam:

```
┌─────────────────────────────────────────────────────────────────────────┐
│  MOTOR 1 — BUILD (EPC)                         Ativado: Ano 1–7        │
│  Cada projeto novo gera R$ 930k de margem imediata                     │
│  50 projetos/ano (Ano 7) = R$ 46,5M/ano                                │
├─────────────────────────────────────────────────────────────────────────┤
│  MOTOR 2 — OPERATE (Receita Recorrente)         Ativado: Ano 1–7       │
│  Portfolio de projetos operando gera fee/receita contínua              │
│  100 projetos (funding) × R$ 1,32M = R$ 132M/ano                      │
│  125 projetos (investidor) × R$ 132k = R$ 16,5M/ano                   │
├─────────────────────────────────────────────────────────────────────────┤
│  MOTOR 3 — TRANSFER (Reciclagem de Ativos)      Ativado: Ano 4–7      │
│  Venda de projetos maduros no mercado secundário                       │
│  30 ativos/ano × ganho líquido R$ 3,5M = R$ 105M/ano                  │
│  ← ESTE É O MOTOR QUE FALTAVA NO PLANO ANTERIOR →                     │
└─────────────────────────────────────────────────────────────────────────┘
```

### 4.1 Motor Transfer — Como Funciona a Reciclagem

Após 4–5 anos de operação, um projeto BOT tem:
- Histórico operacional comprovado (uptime, geração, inadimplência)
- Contrato restante: 5–6 anos de PPA com cliente corporativo
- Valor de mercado (8× EBITDA anual do projeto): ~R$ 8,5–10M

**Economics da venda de 1 ativo maduro:**

```
  Ativo construído há 5 anos (desconto 10%):
  ─────────────────────────────────────────────
  Valor de venda (8× EBITDA proj.):    R$ 8.966.000
  Book value (25 anos vida útil):      R$ 5.270.000  (R$ 6,2M - 5 anos depreciação)
  Saldo devedor (funding, 5 anos):     R$ 3.900.000  (estimado, BNDES 10%)
  ─────────────────────────────────────────────
  Equity liberado:   R$ 8.966.000 - R$ 3.900.000 = R$ 5.066.000
  Ganho sobre book:  R$ 8.966.000 - R$ 5.270.000 = R$ 3.696.000
```

> Compradores dos ativos secundários: fundos de pensão, seguradoras, fundos de infraestrutura,
> family offices — que aceitam retorno menor (CDI + 1–2 p.p.) por ativo operacional com histórico.
> Nós vendemos o que antes era CDI + 6 p.p. para quem aceita CDI + 2 p.p. — **o spread é o nosso lucro.**
