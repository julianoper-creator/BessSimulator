# Estrutura Operacional — Viabilização por Fase
## Modelo BOT de Energia | Headcount, Remuneração e Investimentos

---

> **Referência salarial**: valores em CLT, regime CLT. O custo real para a empresa
> é aproximadamente **1,65× o salário bruto** (FGTS 8% + férias + 13º + INSS patronal ~28% + VT/VR/plano).
> Exemplo: salário R$10.000 → custo empresa ~R$16.500/mês.
